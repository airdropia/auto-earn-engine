Privacy Policy

Last updated: 2026-09-05

Overview

VectorForge Daily (https://airdropia.github.io/auto-earn-engine/) is a fully automated, static website that publishes machine-generated SVG design bundles for free download. The site has no user accounts, no login, no comments, and no analytics tracking.

Data we collect

We do not collect, store, or process any personal data from site visitors. The site sets no cookies of its own and runs no third-party analytics or advertising scripts.

Server logs

Standard GitHub Pages infrastructure may process routine request logs (such as IP addresses) under GitHub's own privacy policy. We do not access or control these logs.

Pinterest API access

Our own automation uses the official Pinterest API, with OAuth 2.0, to publish pins to our own Pinterest account. This access:

  • applies only to the VectorForge Daily account that granted authorization;
  • never reads, stores, or acts on any other Pinterest user's data;
  • does not give this website or its operators access to any visitor's Pinterest account.

Downloads

Product files (SVG and ZIP archives) are served directly as static files. Downloading them requires no account and sends no personal information to us.

Contact

For any privacy question, open an issue at https://github.com/airdropia/auto-earn-engine/issues or use the support links on the main page.

Memorial Shadow Box Size Guide

Here are the common sizes for memorial shadow boxes:

1. A4 size (8.3 x 11.7 inches)

Good for desks and small shelves. All 7 layers fit on A4 cardstock. Portable and easy to gift.

2. 12x12 inch size

The most common size. Good for wall hanging and mantelpieces. More presence, more impact.

3. Deep frame

A shadow box frame with depth built in. No foam tape needed - just stack the layers inside the frame.

4. How to choose

A4 for gifts and small spaces. 12x12 for wall hanging. Deep frame if you want the easiest assembly.

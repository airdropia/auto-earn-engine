# Auto-Earn Engine

A fully automated, zero-cost digital product factory.

- **Runs on**: free GitHub Actions (public repo = unlimited minutes)
- **Publishes to**: free GitHub Pages storefront
- **Costs**: $0 - no paid APIs, no paid hosting, no local compute
- **User input required**: zero ongoing. One optional activation step for payouts (see `docs/SETUP.md`)

## How it works

```
schedule (2x daily cron)
   |
   v
generate_products.py  ->  unique SVG bundles: mandalas, seamless patterns,
                          quote cards, habit trackers (deterministic per date)
   |
   v
build_site.py         ->  zips each bundle, renders static storefront + OG image
   |
   v
git commit            ->  full audit trail of every generated asset
   |
   v
GitHub Pages deploy   ->  live public storefront with download buttons
```

A second workflow (`metrics`) records weekly catalog size and repository
traffic into `metrics/metrics.json`.

## Revenue model (honest version)

Day one the system is operational and publishing. Money flows start when a
payout destination is connected once (Ko-fi / GitHub Sponsors / Gumroad -
all free to join). The storefront already contains automatic monetization
slots that light up from `config.json`. Realistic expectations, growth
levers and platform fee comparisons are documented in `docs/RESEARCH.md`.

## Layout

| Path | Purpose |
| --- | --- |
| `pipeline/generate_products.py` | Daily procedural product generator (stdlib only) |
| `pipeline/build_site.py` | Storefront builder |
| `pipeline/listings.py` | SEO titles / descriptions / tags |
| `pipeline/collect_metrics.py` | Weekly metrics snapshot |
| `.github/workflows/production.yml` | Cron: generate -> build -> commit -> deploy |
| `.github/workflows/metrics.yml` | Weekly traffic/catalog metrics |
| `config.json` | Store name + monetization links (editable in browser) |
| `catalog/catalog.json` | Machine-readable product catalog |
